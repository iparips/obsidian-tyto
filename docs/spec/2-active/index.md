# Active Specs

What is being built right now. Empty means nothing is in flight.

A spec moves here from [1-upcoming](../1-upcoming/index.md) when work starts,
and to [3-archived](../3-archived/index.md) when it lands. It takes its number
on the way out rather than on the way in, so the number says when it shipped.

- [binding-to-the-active-tab](binding-to-the-active-tab/1-index.md) - an empty tab leaves the session bound to the note in the tab before it
- [recording-a-retarget](recording-a-retarget/1-index.md) - making a note change visible in the transcript, the panel and the model's history
