# Active Specs

What is being built right now. Empty means nothing is in flight.

A spec moves here from [1-upcoming](../1-upcoming/index.md) when work starts,
and to [3-archived](../3-archived/index.md) when it lands. It takes its number
on the way out rather than on the way in, so the number says when it shipped.

- [writing-the-session-outside-the-panel](writing-the-session-outside-the-panel/1-index.md) - the record follows the panel's history rather than the turn's end
- [following-the-note-across-a-restore](following-the-note-across-a-restore/1-index.md) - a session binds to the note the user has open, restored or not
