# 0.5.4

Everything since 0.5.1, the last release cut: 0.5.2 and 0.5.3 were tagged but never released.

## Fixed

- An instruction to add something no longer overwrites what is already there. Telling Tyto to add a bullet under a heading could replace the bullet already in it, and there is no undo.
- Tyto no longer reports an edit it just made as something the note already said.
- A search answer cites its notes as links wherever the answer comes out, not only through the answer tool. A reply naming six notes as bare dates gave the reader nothing to click.
- Answers about your vault go through the answer tool, with every note linked. A reply that skips it is sent back once to be redone.
- A reply that is a tool call written as text is caught rather than published to the panel as the answer.
- Vault instructions from the root AGENTS.md or CLAUDE.md are read when no note is open, so a search turn knows the vault's layout.
- A plan is no longer read as a record. Asked what you did, Tyto answers from an entry written afterwards rather than from a note saying what you meant to do.

## Changed

- Note patterns take full shell glob syntax: brace lists like `{Week-35,Week-36}/*.md` and `Week-3{5,6}`, numeric ranges like `Week-{30..40}`, and extglobs like `@(a|b)`, `+(...)` and `!(a)`. One call now covers what several did.
- The README says what Tyto does, what it gets wrong, and why you might want it.
